FIELD GUIDE / OPERATOR LOG

This is a network repair game. First understand what is broken, then use the same steps you'd follow on real infrastructure: observe → isolate → change → verify.

CONTROL ROOM

WASD move, mouse look, E access a nearby device, M toggle the infrastructure map, H this guide, ESC leave computer. Touch devices use an on-screen stick, swipe-to-look and USE button.

DEVICE CONSOLES

Approach DISPATCH-01 for client checks like ipconfig /all, ping, nslookup and tracert. Use CORE-SRV for DHCP/DNS, ACCESS-SW for VLANs, EDGE-RTR for routes and policies. Use PATCH RACK for physical cables. Type help at each device.

LEARNING RULE

The five incidents form one connected network. Fixes drive live status, command results, alerts, and the 3D environment. Mistakes can break earlier services. The game never asks which of four answers is correct.
